# goxt

A minimal task runner for Go projects. Pure Go alternative to Makefile.

## Overview

**`goxt.go`** - Task definitions that work standalone with zero dependencies:
```bash
go run goxt.go test
go run goxt.go build
go run goxt.go deploy prod
```

**`goxt`** - Optional CLI that adds enhanced features:
```bash
goxt init       # Create goxt.go from template
goxt           # Show tasks with descriptions (extracted from godoc)
goxt test -v    # Run task with args
```

## Install

```bash
go install github.com/fxsml/goxt@latest
```

## Quick Start

```bash
# Create goxt.go in your project
goxt init

# Run tasks
go run goxt.go test
# or
goxt test
```

## The `goxt.go` File

Generated by `goxt init`:

```go
//go:build ignore

// goxt.go - Project tasks. Run: go run goxt.go <task>
package main

import (
	"flag"
	"fmt"
	"os"
	"os/exec"
)

func main() {
	tasks := map[string]func() error{
		"test":  Test,
		"build": Build,
	}
	if len(os.Args) < 2 {
		fmt.Println("Tasks:")
		for t := range tasks { fmt.Println(" ", t) }
		return
	}
	if fn, ok := tasks[os.Args[1]]; ok {
		if err := fn(); err != nil { fmt.Fprintln(os.Stderr, err); os.Exit(1) }
	} else {
		fmt.Println("unknown task:", os.Args[1])
		os.Exit(1)
	}
}

// Test runs tests.
func Test() error {
	cmd := exec.Command("go", "test", "./...")
	cmd.Stdout, cmd.Stderr = os.Stdout, os.Stderr
	return cmd.Run()
}

// Build compiles the project.
func Build() error {
	cmd := exec.Command("go", "build", "./...")
	cmd.Stdout, cmd.Stderr = os.Stdout, os.Stderr
	return cmd.Run()
}
```

## Adding Tasks

1. Add entry to the `tasks` map
2. Add function with godoc comment

```go
tasks := map[string]func() error{
	"test":   Test,
	"build":  Build,
	"deploy": Deploy,  // Add here
}

// Deploy deploys to the specified environment.
func Deploy() error {
	// implementation
	return nil
}
```

## Task Parameters

### Simple positional args

Access via `os.Args[2:]`:

```go
// Deploy deploys to an environment. Usage: deploy <env>
func Deploy() error {
	if len(os.Args) < 3 {
		return fmt.Errorf("usage: deploy <env>")
	}
	env := os.Args[2]
	fmt.Println("Deploying to", env)
	return nil
}
```

```bash
go run goxt.go deploy prod
```

### Flag-based args

Use `flag.FlagSet` for complex options:

```go
// Test runs tests. Accepts: -v for verbose, -race for race detection.
func Test() error {
	fs := flag.NewFlagSet("test", flag.ExitOnError)
	verbose := fs.Bool("v", false, "verbose output")
	race := fs.Bool("race", false, "enable race detector")
	fs.Parse(os.Args[2:])

	args := []string{"test"}
	if *verbose { args = append(args, "-v") }
	if *race { args = append(args, "-race") }
	args = append(args, "./...")

	cmd := exec.Command("go", args...)
	cmd.Stdout, cmd.Stderr = os.Stdout, os.Stderr
	return cmd.Run()
}
```

```bash
go run goxt.go test -v -race
```

## Conventions

| Element | Convention |
|---------|------------|
| Task function | Exported, returns `error` |
| Task name | CamelCase → kebab-case (`TestRace` → `test-race`) |
| Description | First line of godoc comment |
| Parameters | `os.Args[2:]` or `flag.FlagSet` |

## How It Works

### `goxt.go`

- Uses `//go:build ignore` to exclude from normal builds
- `go run` ignores build tags, so `go run goxt.go` works
- Simple dispatch: map of task names to functions
- ~30 lines of boilerplate, rest is your tasks

### `goxt`

- Parses `goxt.go` using `go/ast` and `go/doc` (stdlib)
- Extracts exported `func() error` functions as tasks
- Extracts godoc comments as descriptions
- Runs tasks via `go run goxt.go <task> [args...]`

## Comparison with Alternatives

| Tool | Config | Dependencies | Approach |
|------|--------|--------------|----------|
| **goxt** | Go code | None (stdlib) | Convention + optional CLI |
| [Mage](https://magefile.org/) | Go code | mage binary | Build tags, code generation |
| [Task](https://taskfile.dev/) | YAML | task binary | Taskfile.yml |
| Make | Makefile | make, bash | Makefile syntax |

## Why goxt?

- **Zero dependencies**: `go run goxt.go` works without installing anything
- **Just Go**: No YAML, no DSL, no magic - just functions
- **IDE support**: Full autocomplete, refactoring, debugging
- **Portable**: Works on Windows, Linux, macOS
- **Optional tooling**: `goxt` enhances but isn't required
